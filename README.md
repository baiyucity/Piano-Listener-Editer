# 听见 · PianoListener 0.5.0

把演奏录下来，转成可试听、可校对的五线谱和简谱。听见也可以从空白谱面开始写曲，或打开已有的 MIDI、MusicXML 继续编辑。

本包适用于 **Windows x64**。程序和离线识别模型已打包，日常录入、转谱、试听和导出都可离线完成。

## 1. 解压并启动

1. 下载 `PianoListener-0.5.0-Windows-x64.zip`。如果从 GitHub 下载，在 **Releases** 的 **Assets** 中选择这个文件。
2. 在 Windows 文件资源管理器中右键 ZIP，选择「全部解压缩」。进入解压出来的 `PianoListener-0.5.0-Windows-x64` 文件夹。
3. 双击 **`PianoListener.exe`**。程序启动后会显示可试听的示例谱，按空格就可以播放。
4. 保留 EXE 旁边的 `resources`、`locales`、DLL 等文件。移动软件时请移动整个文件夹。可以在桌面创建指向 `PianoListener.exe` 的快捷方式。

程序免安装，无需命令行或另装 Python。要分享免安装版，可以发送原 ZIP。

## 2. 五分钟完成第一份谱

### 方案 A · 直接录一小段

1. 在 Windows 的「设置 → 系统 → 声音 → 输入」选好默认麦克风或声卡输入。先弹两三个音，确认 Windows 的输入电平在动。
2. 打开听见，点左侧「新建作品」。点击顶部作品名称即可改名。
3. 如果录的是独奏钢琴或电钢琴，可以在「偏好设置 → 录音与识别」选择「钢琴专用 · Transkun」。这个模式会估计力度和延音踏板。想先试其他音色，选择「轻量多音 · Basic Pitch」。点「保存设置」。
4. 在谱面或 MIDI 透镜上左键定位。点击「开始录入」或按 `Alt+空格`，弹奏一小段。开启实时预览时，录音期间会间隔几秒更新一次临时音符。
5. 点击「结束并复核」或再次按 `Alt+空格`。等待本轮分析结束，谱面会显示整理后的音符。首次加载模型可能稍慢。
6. 点击底部「音符」或「原录音」切换试听来源。点在谱面上定位，按空格从当前位置播放。检查后按 `Ctrl+S`，保存为 `.pianolistener` 工程。

**录音小技巧。** 第一遍用安静环境和较短乐句试录。弹几下最响的音确认电平不过载，给最后一个音留一点自然尾音。电钢琴既可以用麦克风收音，也可以通过声卡录入。试听时戴耳机可减少声音被麦克风再次收进来。

### 方案 B · 从手机或电脑录音开始

1. 将录音传到电脑。点击「导入音频 / 乐谱」并选择音频文件，例如 WAV、MP3 或 FLAC。
2. 等待本地分析。已启用自动调性和速度估计时，初步结果会写到谱头。在右侧「调性与节拍」可改调号、速度、拍号，也可重新运行「自动识别调性」。
3. 打开「录音复核」。播放原录音时观察指针，或拖动底部波形寻找某一段。拖动时可预览位置，松手后谱面会跟到对应行，`Esc` 可取消这次拖动。
4. 如果录音开头有一段空白，可在「偏好设置 → 录音与识别」调整「录音起拍偏移 / 秒」，保存后再执行「对照录音复核」。
5. 保存工程后，再按需要导出 MIDI 或 MusicXML。

## 3. 从空白谱面打谱

### 鼠标加音

1. 点击「新建作品」，在顶部切换「五线谱」「简谱」或「对照」。这三个视图共用同一条音符时间轴，修改会同步反映到其他视图。
2. 在空白谱面上右键，选择符值轮盘中的四分、八分等时值。按住 `Shift` 可升半音，按住 `Ctrl` 可降半音，两键同时按住会抵消。
3. 左键点已有音符可以选中，拖动可修改音高和起拍。右侧面板可改时值、力度、延长记号、踏板。展开「精确参数」可输入 MIDI 音高、起拍、时值、左右手和声部，输入后按回车确认。

### 键盘加音

1. 打开顶部「按键加音」，左键点击谱面或透镜设置起点。
2. 按 `A`–`G` 输入音名，或按 `1`–`7` 输入当前调号下的首调音级。按下开始推进时间，松开后写入时值。可重叠按住多个键输入和弦。
3. 用 `[` / `]` 降低或升高八度。按住 `Shift` / `Ctrl` 可持续升降半音。`0` 将指针前移一个工具栏符值，留出空拍。
4. 按 `Esc` 退出按键加音。按键时值取决于实际按住的时间，并按拍内网格量化。需要精确指定某个符值时，可以改用鼠标轮盘或右侧参数。

### 叠加和插入

| 模式 | 什么时候用 | 编辑结果 |
| --- | --- | --- |
| 融合（单竖线） | 给已有旋律叠加低音、和弦或第二遍演奏 | 新音从指针处与原有音符并行，后续时间位置保持原样 |
| 插入（双竖线） | 在乐句中间加一拍或插入一段演奏 | 新内容占据插入时长，后续音符、踏板及关联录音随之顺延 |

用顶部「融合 / 插入」或双击谱面指针切换模式。右键、键盘和录入都遵循当前模式。想叠加第二遍演奏时，先选「融合」，点击目标位置，再按 `Alt+空格` 开始。完成后可用 `Ctrl+Z` 撤销本次操作。

### 小节、透镜与延音

- 默认允许鼠标加音跨小节，持续音在下一小节会显示延音线。打开「限制当前小节编辑」后，越界的鼠标加音、拖动和时值修改会被拒绝。键盘和录音仍可跨小节。
- 若两个相接小节里已有首尾相接的同音高音符，右键第一个音选择「从此音开始延音连接」，再右键后一个选择「连接到此音」。
- 鼠标点小节后在谱面上按 `Ctrl` 滚轮，可调小节宽度。后续小节会自动补位。窗口内的排布可随屏幕和密度调整。
- 打开「透镜」可查看当前谱行的 MIDI 音条。左键定位，右键可选择二分至三十二分音符的刻度网格，方便判断起拍和音长。切换透镜刻度不会移动谱中的音。
- 延音线表示相连的记谱时值。延长记号写入乐谱供演奏者阅读。延音踏板另有自己的时间区间。

## 4. 试听和校谱

1. 点侧栏「录音复核」或谱面上方的「待检查」。用「跳到下一个待检查音符」逐个定位。
2. 先对照原录音，再切到「音符」试听谱面。橙色表示建议检查或引擎分歧，红色表示优先检查。「评分未知」表示引擎没有给该音单独评分。
3. 有关联录音时，可以运行「对照录音复核」。钢琴模式下，另一识别器独有的结果可作为备选音符，试听后选择添加或忽略。已保护的手动修改会保留。
4. 优先核对漏音、重复音、八度和时值。密集和弦、踏板重叠、混响与合奏都可能需要手工修正。「疑似音色」是分段标签。快速试听时可参考它，实际的乐器声部仍需自行整理。

复核同一段录音会使用相同的确定性模型。如果结果始终有误，可以直接编辑，或换一段收音更清楚的录音。关于准确率、踏板与音色边界，见 [识别说明](docs/识别说明.md)。

## 5. 保存、导出与分享

| 文件 | 用途 | 操作 |
| --- | --- | --- |
| `.pianolistener` | 留着继续编辑，保存谱面和已关联的录音 | 点击「保存」或按 `Ctrl+S`；下次用「导入作品」打开 |
| MIDI（`.mid`） | 发送给 DAW、合成器或其他支持 MIDI 的软件 | 顶部「导出」选择 MIDI |
| MusicXML（`.musicxml`） | 交给其他打谱软件继续排版或打印 | 顶部「导出」选择 MusicXML |
| WAV（`.wav`） | 单独保存关联的录音 | 作品有关联录音时，在「导出」菜单选择录音导出 |

也可导入 MIDI、MusicXML 和压缩 MusicXML（`.mxl`）。MusicXML 导出按每行六小节写入布局提示，其他打谱软件可能使用自己的排版。MIDI 保存音乐时间信息，无页面排布。

**保存提醒。** 自动恢复主要保存谱面。录完后请保存工程，换电脑时把工程一起带走。工程中可以包含你录下的音频，分享前请确认是否适合一并发送。

## 6. 外观、音源和可选智能辅助

- **主题。** 点击顶部主题名，或打开「偏好设置 → 外观」。内置「星河」和「水墨」，还可以用色环或 HEX 选择主题色，导入本地 PNG、JPEG、WebP 作为背景。拖动预览调整取景，按 `Home` 居中。满意后点击「保存外观」。
- **减少动效。** 偏好设置的外观页可跟随系统或减少动效。想扩大乐谱区域，点击顶部「专注谱面」。要恢复右侧工具，可点击「面板」。
- **回放音源。** 「偏好设置 → 回放」可使用内置轻量合成音，也可检测并选择外接 MIDI 输出。这个版本使用麦克风或音频文件来转谱，尚无 MIDI 输入录谱。
- **智能辅助。** 默认关闭。确实需要时，在「偏好设置 → 智能辅助」填写兼容 OpenAI Chat Completions 的接口地址、模型名和 API Key。点击右侧「检查选中音符」才会把谱面上下文发给指定服务。原始录音留在本机，建议需要经你确认后才会应用。密钥由 Windows 本地加密保存在当前用户的应用设置中，工程文件不会包含密钥。服务商可能收费。

## 7. 常用快捷键

| 快捷键或操作 | 功能 |
| --- | --- |
| `空格` | 从当前位置播放或暂停 |
| `Alt+空格` | 开始录入或结束并复核 |
| `Ctrl+S` | 保存工程 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Delete` | 删除选中的音符 |
| `←` / `→` | 在谱面定位 |
| `↑` / `↓` | 调整所选音符的音高 |
| `A`–`G` 或 `1`–`7` | 开启按键加音后录入音符 |
| `Shift` / `Ctrl` | 加音时升 / 降半音 |
| `[` / `]` | 降 / 升八度 |
| `0` | 按键加音时留空拍 |
| 双击谱面指针 | 切换融合与插入 |
| 小节上 `Ctrl` + 滚轮 | 调整该小节宽度 |
| `Esc` | 退出按键加音或取消正在进行的定位拖动 |

## 8. 遇到问题

| 现象 | 检查方法 |
| --- | --- |
| 双击后打不开，或提示缺少文件 | 确认已用「全部解压缩」解出整个目录，并从解压后的文件夹启动。下载后出现 Windows 发布者提示时，先核对下载来源。 |
| 麦克风没声音 | 在 Windows 的「隐私和安全性 → 麦克风」检查是否允许桌面应用访问，再到系统声音设置确认默认输入和输入电平。切换输入设备后可重新启动听见。 |
| 长时间停在分析 | 首次加载模型或使用钢琴专用处理长录音时，等待时间会更长。可以先用几十秒录音和轻量多音模式检查。到「偏好设置 → 录音与识别」确认本地引擎状态。 |
| 播放没声音 | 确认 Windows 音量、回放音源和输出设备。试着切回内置轻量音色或换到「原录音」比较。 |
| 调号或节奏有偏差 | 先调整录音起拍偏移，再检查右侧调号、速度和拍号。自由速度、复杂拍号和多次转调可能需要手动整理。 |
| 录音导入失败 | 先尝试导出原音频为 WAV，然后重新导入。 |
| 键盘没加出音符 | 打开「按键加音」，点一下谱面或透镜，然后按住音名键并松开。焦点在文本输入框或对话框时，先回到谱面。 |
